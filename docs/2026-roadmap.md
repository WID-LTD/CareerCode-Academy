# CareerCode 2026 Roadmap

## Implemented
- Project workspace: kanban tickets, standups, retrospective
- Oral defense upload and instructor review
- Employer-verifiable skill badges with public verification
- Real client project board and applications
- Peer review queue
- Spaced review queue
- Sandbox launch links for every course
- Learning event tracking API
- AI-Assisted Engineering module (4 lessons, 12 quiz questions)
- Instructor Hub Reviews page

## Days 1-30
- Pilot project workspace with one cohort
- Add oral defense requirement to capstone
- Award first badges from real evidence
- Pilot StackBlitz/Codespaces in beginner course
- Track activation and first-deploy metrics

## Days 31-60
- Add rubric-based badge review
- Run peer review sessions
- Launch first WID LTD client project
- Add spaced review prompts to To-Do/notifications
- Review learning analytics for stuck points

## Days 61-90
- Employer verification portal
- Apprenticeship/placement tracking
- Cohort accountability programme
- Public project showcase with verified evidence
- AI-assisted engineering assessment

## Metrics
- first-deploy activation
- lesson completion
- project submission and verification rate
- oral defense pass rate
- badge awards
- peer review participation
- spaced review retention
- 30/90-day retention
- client project completion
- employer verification views
